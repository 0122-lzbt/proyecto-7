Herramientas de Desarrollo de Software - Proyecto Sprint 7
Este proyecto consiste en una aplicación web interactiva desarrollada con **Streamlit** y **Plotly Express**, diseñada para analizar un conjunto de datos de anuncios de venta de vehículos en los Estados Unidos ('vehicles_us.csv').

Funcionalidad de la aplicación:
-Visualización de Histogramas:** Un botón interactivo que genera un histograma para analizar la distribución de la condición de los vehículos según el año del modelo.
-Gráficos de Dispersión:** Un botón interactivo que despliegaun gráfico de dispersión para examinar la relación directa entre el precio de venta y el kilometraje (odómetro) de los automóviles.

Cómo ejecutar la aplicación localmente:
1. Asegúrate de tener las dependencias instaladas: 'pip install -r requirementes.txt'
2. Ejecuta el comando en tu Terminal: 'streamlit run app.py'
